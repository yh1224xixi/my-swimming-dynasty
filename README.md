# 我的游泳王朝 V10.1 · 修复分支

基于《我的游泳王朝》现实泳坛名将版。直接双击 index.html 可运行；无需安装运行依赖。

V10.1 修复游泳动画与计时、接力、训练和奖励结算、长距离统计、赛季历史、广告续约、名将身份及游泳文案。完整对应实测问题的说明见 [FIXES_V10.1.md](FIXES_V10.1.md)。

## 开发回归

Node.js 24.15 或更新版本：

```sh
npm ci
npm test
```

测试不修改线上存档或正式代码。JSDOM 回归涵盖核心公式、存档、人物创建和连续赛季；泳池画面与手机触控需在浏览器预览站验收。

## 已新增
- 现实运动员客串名单扩展，按男女组别融入原有 AI 对手池，不新增未经证实的真人数据。
- 延续原游戏的年龄、巅峰、竞技衰退、年度换血和竞赛模拟。
- 每赛季保存泳坛模拟实力榜快照及年度前三名，展示在「泳坛中心」。
- 新增按男女和距离分组的动态实力排名、名将资料卡、PB 对照宿敌情报、重大赛事对阵预览、历史排名页面。
- 所有模拟榜单与真实国际泳联成绩分开标注。

## 限制
- 当前收录的是选定的现实知名运动员，不是所有现役运动员；真实比赛结果不被导入。
- 历史榜为游戏 AI 实力年度快照，不等于实际赛事金银铜牌。
- 内部沿用旧项目编号以兼容存档；纪录采用冻结的 2024 年长池参考，达标线和模拟排名是游戏规则，并非最新官方数据。
- 全量现实运动员需要公开且合法的完整选手资料源、项目/性别/活跃状态和长期更新机制。
