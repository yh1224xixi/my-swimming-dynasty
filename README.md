# 我的游泳王朝 V10 · 泳坛生态整合版

基于《我的游泳王朝》现实泳坛名将版原始游戏程序。直接双击 index.html 可运行。

## 已新增
- 现实运动员客串名单扩展，按男女组别融入原有 AI 对手池，不新增未经证实的真人数据。
- 延续原游戏的年龄、巅峰、竞技衰退、年度换血和竞赛模拟。
- 每赛季保存泳坛模拟实力榜快照及年度前三名，展示在「泳坛中心」。
- 新增按男女和距离分组的动态实力排名、名将资料卡、PB 对照宿敌情报、重大赛事对阵预览、历史排名页面。
- 所有模拟榜单与真实国际泳联成绩分开标注。

## 限制
- 当前收录的是选定的现实知名运动员，不是所有现役运动员；真实比赛结果不被导入。
- 历史榜为游戏 AI 实力年度快照，不等于实际赛事金银铜牌。
- 原游戏仍含少量从田径基底移植而来的规则；本次不重写底层赛事。
- 全量现实运动员需要公开且合法的完整选手资料源、项目/性别/活跃状态和长期更新机制。
